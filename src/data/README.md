# src/data

Tải dữ liệu, làm sạch văn bản, loại trùng, chia split, tokenize, vocab, Dataset/DataLoader.

**What belongs here:** `download.py`, `clean.py` (làm sạch HTML, chuẩn hoá, hash loại trùng), `split.py` (group split theo `movie_url`), `vocab.py` (ghi/đọc `vocab.json`), `dataset.py`.

**What does not:** Định nghĩa mô hình, vòng train.
